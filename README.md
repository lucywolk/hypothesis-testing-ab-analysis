# Проверка статистической гипотезы и анализ A/B-теста

Учебный аналитический проект на Python, состоящий из двух независимых исследований: сравнения активности пользователей сервиса «Яндекс Книги» и оценки результатов A/B-теста интернет-магазина BitMotion Kit.

**[Открыть исследование в Jupyter Notebook](yandex_books_ab_test_portfolio.ipynb)**

## Часть 1. Активность пользователей «Яндекс Книг»

**Цель:** проверить гипотезу о том, что пользователи Санкт-Петербурга проводят в приложении больше времени за чтением и прослушиванием книг, чем пользователи Москвы.

**Этапы работы:**
- Загрузка и проверка данных, обработка повторяющихся идентификаторов пользователей.
- Сравнение размеров групп и распределений времени активности.
- Проверка односторонней статистической гипотезы с помощью t-теста Уэлча.
- Подготовка аналитического вывода.

**Результат:** статистически значимого превышения средней активности пользователей Санкт-Петербурга над Москвой не обнаружено (односторонний p-value = 0,332 при уровне значимости 0,05).

## Часть 2. A/B-тест интернет-магазина BitMotion Kit

**Цель:** оценить влияние нового интерфейса сайта на конверсию пользователей в покупку.

**Этапы работы:**
- Проверка качества данных о пользователях и событиях.
- Анализ распределения участников по экспериментальным группам и выявление пересечений с другим тестом.
- Ограничение периода анализа первыми семью днями с момента регистрации.
- Оценка достаточности выборки и расчёт конверсии в покупку.
- Статистическая проверка различий с помощью z-теста пропорций.

**Результат:** конверсия в группе B оказалась выше на 2,48 процентного пункта (относительное изменение — 7,5%). Различие признано статистически значимым, однако наблюдаемый прирост ниже планируемого эффекта в 10%. В исследовании рекомендовано дополнительно оценить влияние обновления на выручку и средний чек перед принятием решения о внедрении.
